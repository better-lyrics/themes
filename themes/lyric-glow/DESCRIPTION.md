# Lyric Glow

An Aurora Cinematic, typography-first theme for Better Lyrics.

Lyric Glow turns YouTube Music into an immersive lyric canvas: album-art colors fill the scene, cyan, violet and rose auroras add depth, the current lyric receives a soft diffuse glow, upcoming lines stay readable for anticipation, and previous lines recede naturally.

## Highlights

- Aurora lyric stage - active lyrics are emphasized with light, typography and a restrained three-color atmosphere.
- Native rich sync - Better Lyrics keeps control of word/syllable timing, swipe, wobble and glow animations.
- Forward-reading hierarchy - the next lines remain readable while already-sung lyrics recede.
- Voice-aware layout - secondary/tertiary vocals and shared-vocal sections receive direction-aware presentation.
- Translations and romanization - styled as subtle secondary captions.
- Dynamic album-art ambience - blurred artwork remains as a fallback when the shader extension is unavailable.
- Optional Kawarp shader - shader.json is tuned for smooth, efficient motion and contained audio response.
- Glass interface - navigation, menus, dialogs, queue and player controls share a cohesive translucent design.
- Responsive layout - tuned for normal player view, fullscreen and narrower desktop windows.
- Accessibility - includes reduced-motion and increased-contrast fallbacks.
- No external font dependency - uses the best native system font available.

## Recommended Setup

Use the latest Better Lyrics version, keep album-art/background features enabled, and install [Better Lyrics Shaders](https://github.com/better-lyrics/shaders) if you want the animated Kawarp background. Import this theme's shader.json through the shader extension popup.

The shader is optional. The CSS theme remains usable with the static blurred album-art background alone.

## Compatibility

Minimum Better Lyrics version: 2.4.0.1

Lyric Glow uses modern browser features including :has(), masks and backdrop-filter, and is primarily designed for the desktop YouTube Music interface.

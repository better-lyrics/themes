# Lyric Glow

A cinematic, typography-first theme for **Better Lyrics**.

Lyric Glow turns the YouTube Music player into an immersive lyric canvas: album-art colors fill the scene, the current lyric receives a soft diffuse glow, upcoming lines stay readable for anticipation, and previous lines naturally fall into the background.

## Highlights

- **Lyric Glow stage** — active lyrics are emphasized with light and typography instead of visible cards.
- **Native rich sync** — Better Lyrics keeps control of word/syllable timing, swipe, wobble and glow animations.
- **Forward-reading hierarchy** — the next lines remain readable while already-sung lyrics recede.
- **Voice-aware layout** — secondary/tertiary vocals and shared-vocal sections receive direction-aware presentation.
- **Translations & romanization** — styled as subtle secondary captions.
- **Dynamic album-art ambience** — blurred and toned artwork creates a cinematic background without overpowering the lyrics.
- **Glass interface** — navigation, menus, dialogs, queue and player controls share a cohesive translucent design.
- **Responsive layout** — tuned for normal player view, fullscreen and narrower desktop windows.
- **Accessibility** — includes reduced-motion and increased-contrast fallbacks.
- **No external font dependency** — uses the best native system font available.

## Recommended Setup

Use the latest Better Lyrics version and keep album artwork/background features enabled for the intended visual experience.

## Compatibility

Minimum Better Lyrics version: **2.4.0.1**

Lyric Glow uses modern browser features including `:has()`, masks and `backdrop-filter`, and is primarily designed for the desktop YouTube Music interface.
